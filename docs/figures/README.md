# Скриншоты для отчёта

Положите файлы в эту папку под указанными именами и пересоберите отчёт:

```bash
python scripts/build_report.py
```

Генератор сам подставит картинку над подписью. Если файла нет, в отчёте
останется только подпись «Рисунок N — …», а структура не сломается.

**Как снимать на macOS:** `Cmd + Shift + 4`, затем выделить область.
Файл появится на рабочем столе — переименуйте и перенесите сюда.

## Практика 1

| Файл | Что должно быть на снимке |
|---|---|
| `fig_01_architecture.png` | Схема архитектуры: источники → raw → clean → mart → модель → дашборд. Рисуется в draw.io, Figma или PowerPoint, затем экспорт в PNG. Обязательный материал по методичке, раздел 6, пункт 3. |
| `fig_02_repository.png` | Дерево файлов проекта. Панель Explorer в VS Code с раскрытыми папками `src`, `tests`, `docs`, либо вывод команды `tree -L 2` в терминале. |

## Требования к качеству

- Снимайте **окно целиком**, чтобы была видна команда и её результат — проверяющий должен понимать, откуда взят вывод.
- Не обрезайте строку приглашения терминала: она подтверждает, что команда выполнялась реально.
- Увеличьте шрифт терминала перед съёмкой (`Cmd +`), иначе текст в печати будет нечитаем.
- Формат PNG. Ширина в отчёте — 16 см, поэтому снимок шириной менее 800 пикселей будет выглядеть размытым.
